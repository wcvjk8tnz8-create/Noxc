# 站点设置（管理员）

以下都在后台「站点设置」里改，保存即生效，不用重新部署。

## 品牌与公告

| 项 | 说明 |
|---|---|
| 站点名称 / Logo / favicon | 导航、标题、浏览器标签 |
| **站点公告** | 纯文本最多 300 字，留空不显示。保存后全站每页顶部都出现（控制台、首页、登录、文档、根域名落地页），按纯文本渲染、不解析 HTML，也不随界面语言翻译 |
| 页脚备案号 / 联系方式 | 贴 `<a>` 链接即可，留空隐藏 |

## 注册与验证

- 注册滑块验证开关与图库子集；弹窗只在提交时出现，管理员手动开通豁免
- 邮箱白名单与第三方邮箱申请通道
- 按根域名设置每人注册次数
- 域名有效期与续期窗口（留空时按有效期一半自动推算）

## 按后缀单独暂停新申请

在「站点设置 → 按后缀单独暂停新申请」里勾选某个根域名，**只有该后缀不再接受新的域名申请**，其它后缀照常开放。

- 首页后缀卡片标「暂停申请」，查询结果不再出现「立即注册」
- 注册页切到该后缀会锁定并提示；切回开放后缀自动解锁
- WHOIS 仍可查询；管理员仍可自建域名
- **已注册域名的 DNS 记录、续期、转移、展示与签到全部不受影响**
- 提示语复用「暂停提示语」；不填则用带后缀名的默认文案
- 环境变量 `ROOT_APPLY_PAUSED=meoy.top,v-1.top` 可强制暂停，后台清空也关不掉

与「按根域名设置每人注册次数」是两个独立维度：一个管「还能不能申请」，一个管「每人能申请几次」。

## 第三方域名接入（外部域名）· 固定 SEUS DNS

独立页面：<a href="/external-domains">`/external-domains`</a>（文档式说明 + 提交申请，可直接打开 / 刷新 / 外链跳入），控制台「**注册域名**」卡片下面与注册页底部也有入口；服务文档另见 [第三方域名接入](/external-domains.html)。列表与 WHOIS 结果统一标 **（外部域名）**。

**流程**

1. 填写你自己的完整域名：**只允许 gTLD 二级域**（如 `xxx.com` / `xxx.xyz` / `xxx.top`）。
   `xxx.example.com` 这类**子域名不受理**；`.cn` / `.uk` / `.cc` / `.io` / `.ai` 等 ccTLD
   不受理；`example.com` 等文档示例域不受理；本站生效后缀也不能冒充外部域名。
2. **在域名「当前」的 DNS 服务商**添加页面给出的 `_noxc-verify.<域名>` TXT，
   点「**验证 TXT**」。**验证通过前不要改 NS**：NS 切到 SEUS 后这条 TXT 就不再被
   全球 DNS 查询，验证会永远失败。
3. 验证通过后，才到域名注册商把 **NS 改为 `a.ns.fs5.net` / `b.ns.fs5.net`**，
   并先在 s.eus 完成该域名的 DNS 托管（BYOS 需 KYC L2 与人工审核，本站不代做）。
4. 点「**用 API 连接**」：站长在「**站点设置 → 第三方域名接入**」的**唯一输入框**
   里填一次 `mbt_` MCP Token，**保存即生效** —— 不用配环境变量、不用改 Worker
   Secret、不用重新部署，Zone 也会按域名自动查。站点用这个 Token 调官方
   `dns_zones` 找到托管区域与 zone id。**留空也能用**：站点没配令牌时，用户可
   临时填自己的 Token，**仅本次连接使用、不保存**。**未验证 TXT 时该按钮与接口都不可用**。
5. **等待站长批准**：申请出现在「站点设置 → 第三方域名接入」审批列表，
   只有 **TXT 已验证** 且已连上 SEUS zone 的申请能批准；批准后域名成为根域名，
   可在该后缀下申请子域。

**固定 SEUS DNS**：表单里没有供应商选择。批准后该域名在「根域名管理」里的
DNS 后端下拉禁用并标「SEUS DNS · 第三方接入（固定）」，管理员也不能切换；
所有 DNS 记录由站点后端用 SEUS API 写入。

> **最容易踩的坑**：① **先改 NS 再补 TXT 验证** —— 顺序反了就永远验证不过，
> TXT 必须加在「当前」权威 DNS 上；② 连接 API / 写入记录都只作用在 SEUS 的托管区域里。
> **注册商 NS 没改之前，全球 DNS 不会向 SEUS 查询**，写进去的记录等于没生效。
> 接口返回里带 `nsWarning`，审批列表也会标「NS 待确认」。
> 详见 README 文末「附录 Z.5 / Z.14」。

**边界与安全**

- 独立表 `external_domains` + 按用户索引；**不占注册配额、不计入站点统计、不写本站 DNS**
- 本站生效后缀下的名字（含根域名本身）不能登记，仍走注册页
- 每个账号最多 5 个；未批准的申请可撤回，已批准的由站长在根域名管理里处理
- **站点级 SEUS Token 只有一个来源**（后台 `settings.seus_api_token`），只存服务端，
  后台只回掩码、`/api/config` 只有布尔值、脱敏备份会置空；用户临时填的 Token
  只在本次请求内存里用
- **先 TXT 验证、后改 NS**：用户在当前 DNS 服务商加 `_noxc-verify` TXT 并验证通过，
  才允许改 NS / 连接 SEUS API / 站长批准（三处后端都复核 `verify_status`）。
  TXT 加在「当前」权威 DNS 上，NS 切走后就查不到了，顺序不能倒

## D1 读取优化

免费版 D1 每日 5M rows read。公开统计改为 `settings` 表一行 JSON 快照（10 分钟重算一次，读取只花 1 行），`/api/config` 整响应缓存 30 秒并加浏览器 `Cache-Control`，前端后台刷新节流 60 秒，注册页输入 600ms 防抖 + 15 秒结果缓存。写操作由全局中间件统一失效缓存。详见 README 文末「附录 Z.1」。

## 暂停后自动切到主推域名

「暂停申请」只影响**能不能新注册**，不代表后缀不存在：它仍是站点后缀，已有域名照常解析、续期、展示，首页统计里也照常列出。

- **可申请入口**（首页后缀卡片与查询下拉、WHOIS 下拉、根域名落地页下拉）剔除暂停后缀
- **注册页后缀选择器**里暂停项**照常显示，但灰掉、不能点击**（`disabled` + 灰色 + `pointer-events:none`），右侧标「暂停」

- 主推域名为 `noxc.uk`（首页标「首推」）；若它也暂停，自动落到下一个开放后缀
- 通过 `/register?root=暂停后缀`、首页/WHOIS/落地页旧链接带暂停后缀进来，会**自动切换到主推域名**并改写 URL，刷新不会跳回
- 后台中途暂停了当前选中的后缀，注册页会立即自动切主推，不会把后缀选择器锁死（旧版切进去就切不回来）
- 后缀选择器在暂停态**永远可点**：里面既能看到开放后缀，也能看到灰掉的暂停后缀，不会「切过去就切不回来」
- 首页**统计展开明细照常列出全部生效后缀**（含被暂停的 `meoy.top`），暂停行只加一个灰色「暂停申请」标注；「最热后缀 HOT」按真实已开通数量算，不因暂停隐藏；统计总数仍是全站真实值
- 全部后缀都暂停时没有可切目标，保持「提交注册」硬锁

## 暂停后无法点击提交注册

按后缀暂停后，注册页的「提交注册」按钮会被**硬锁**，不是只靠后端报错：

- 按钮 `disabled` + `aria-disabled` + CSS `pointer-events:none`，旧缓存 JS 也点不动
- 点击入口、滑块验证回调、`doSubmit()`、待审核列表异步回来，四处都会再核一次当前后缀
- 滑块验证弹窗在暂停态不会打开；已打开的会被立刻关闭
- 前端不区分管理员，一律锁；后端注册接口仍返回 403 作为最后一道，管理员自建豁免
- WHOIS 结果不再出现「申请这个域名」入口

从首页、WHOIS 或根域名落地页带 `?root=` 跳进注册页，同样按该后缀判定。切回未暂停后缀会自动解锁。
