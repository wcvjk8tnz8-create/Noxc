# DNS 记录

## 切换域名

域名详情页顶部有「切换域名」下拉。选中另一条域名后会**整页重载**，页面标题、概览、DNS 记录列表、NS 委派状态与「用户案例展示」设置一起更新，并保留当前所在的标签页。

「自助验证」卡片里的「当前操作域名」是**只读说明**，不是切换器：验证记录固定写在当前域名所属的根域名下。以前这里有一个局部「选择域名」下拉，却只改验证写入目标、不切换整页 —— 切到别的域名后下方记录仍是旧的，接着点「添加记录」又写回原域名，容易被误认成凭空多出一条重复记录。现在换域名一律走顶部下拉。

## 重复记录保护

保存按钮点击后立即禁用并显示「保存中…」，响应慢时连点不会提交两次；后端对**同名、同类型、同值**的记录做幂等返回，不会在 Cloudflare 写出第二条。同类型不同值（例如多个 AAAA）或不同主机名仍是合法的多条记录，不受影响。

## 支持的记录类型

A、AAAA、CNAME、MX、TXT、NS、CAA、SRV、PTR、SPF、DS、HTTPS 等，共 12 种，均支持自定义 TTL。

## NS 记录

**NS 记录也是普通 DNS 记录**：和 A / TXT 走同一套接口、同一张表，添加后出现在记录列表里，可编辑可删除。

在「域名管理 → DNS 记录」卡片标题栏有「一键添加 DNSHE」按钮，点一次写入两条预设 NS，重复点不会产生第二组。

::: warning 两组 NS 不要混用
- `ns1.dnshe.org` / `ns2.dnshe.org`：**外部域名托管到 DNSHE** 用的 NS 主机
- `ns1.dnshe.com` / `ns2.dnshe.com`：**专属于在 DNSHE 注册的域名**的 NS 服务器
- `api005.dnshe.com` 是 WHOIS / DNS REST 的 API 网关，**不是 NS 主机**

:::

## NS 委托

「NS 委派」页只写两条 NS 记录，**不转移解析权**，也不改动注册商处的设置。取消托管会按当前预设删除对应记录。

选择 **anyns.io**（n.ht 社区）时，可填入面板创建的 `nhtdns_` **管理令牌**：
本站会先查再幂等创建解析区域，并把它返回的 `zone.ns` 写进 NS 记录；
DDNS / ACME 令牌不能用于管理接口（服务端会返回 `token_scope_mismatch`）。
令牌只在本次请求中使用，不保存。已托管后可用同一令牌「检查委派」——
注意 AnyNS 官方没有独立的委派校验端点，这里只查区域状态与它记录的 NS，
注册商 NS 是否生效请用 `dig NS` 或其面板确认。

## 暂停解析（meoy.top 迁移中）

`meoy.top` 正在迁移至 AnyNS。迁移期间该后缀下所有子域名的状态显示为
**「暂停解析」**，控制台与域名详情页顶部会显示
「meoy.top 正在迁移至 anyns」。普通用户暂时不能增删改 DNS 记录，
**查看已有记录、WHOIS 查询、续期、用户案例展示与公开统计都不受影响**；
管理员仍可操作，迁移记录由站点后端的 AnyNS 管理令牌补进根域名区域。

这里不需要普通用户填任何 API key：管理员在「站点设置 → AnyNS」填入
`nhtdns_` 管理令牌（或配置 Worker Secret `ANYNS_API_TOKEN`，优先级更高），
DNS 记录就会写到 AnyNS 的 `meoy.top` 区域。令牌只存服务端，页面只回掩码。
迁移完成后管理员在同一张卡片清空「暂停解析根域名」即一次性恢复。

## 平台验证

根域名验证用 TXT 记录，控制台提供一键写入与重新校验。Cloudflare 代理开关仅对支持的记录类型生效。
