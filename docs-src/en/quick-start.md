# Quick start

## 1. Create an account

Sign up with an email and password, then enter the verification code. NodeLoc and GitHub login are also available.

New users start with **100 points** and the site's default free domain quota.

## 2. Pick a suffix

The home page "Suffixes" section lists the active root domains; `noxc.uk` is first and labelled "Recommended". Each suffix may cost a different number of points, shown on its card.

::: info HOT badge
The suffix with the **most registered subdomains** is marked `HOT` on the home page. Click "Domains registered" to expand a per-suffix breakdown.
:::

## 3. Check and apply

Enter a label in the search box, choose a suffix, then hit "Register". A slider captcha dialog opens **only when you submit**. Applications are either approved instantly or reviewed by an admin.

Admins creating names manually are exempt from the captcha.

## 4. Add records

Open "Domain management → your domain" to add A / AAAA / CNAME / MX / TXT / NS records, or use one-click platform verification writes.

> NS records are ordinary DNS records — they appear in the record list and can be edited or deleted.

## 5. Expiry and renewal

The validity period is set in "Site settings → Domain validity" (default 365 days). **Renewal opens once less than half the period remains** (182 days for 365). The window can also be pinned to a fixed number of days.

The "registered for X days" text on the home page follows the live setting.
