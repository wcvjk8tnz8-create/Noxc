# 账号与额度

## 积分规则

后台「站点设置 → 积分规则」可改，当前默认：

| 项目 | 数值 |
|---|---|
| 每日签到 | +30 |
| 新用户初始 | 100 |
| 普通域名消耗 | −60 |
| 单字域名消耗 | −300 |

页面上的说明文字由 `/api/config` 实时下发，后台改了不会留在旧数字。管理员与 `-1`（不限量）账号跳过扣减，积分上限 10000。

## 增加配额

- **绑定 NodeLoc**：首次绑定 +5，同一账号只发一次
- **绑定 GitHub 并给项目点 Star**：实时向 GitHub 复核，每账号一次 +5
- **展示你的域名**：首次把已开通域名开启「用户案例展示」→ 一次性 **+6000**，每账号只发一次，关闭不回收

绑定与解绑在「个人资料」里操作，第三方登录需管理员先在后台配置应用凭据。

## 每人注册次数

后台可以按根域名单独限制每人注册次数，例如 `meoy.top:1`、`noxc.uk:-1`（不限）。释放域名不退还次数，**功能上线前已注册的用户不受影响**。

## 邮箱与登录

- 支持邮箱验证码注册、更换邮箱、修改密码（都是发码到当前绑定邮箱，不问原密码）
- NodeLoc 登录会读取真实邮箱，不再生成 `@oauth.local` 乱码账号
- `ns1/ns2.dnshe.com` 一类地址不再被误判为「含 edu 就能注册」的漏洞入口

## 举报与封禁

被封账号无法借第三方登录回来。对封禁有异议，可通过[举报通道](https://nic.299282.xyz/report)或站点公告里的联系方式申诉。
