# 关于 Noxc

Noxc 是一套运行在 **Cloudflare Workers + D1** 上的免费二级域名分发与 DNS 管理系统。

你在这里申请 `<前缀>.<根域名>`，拿到一个独立子域名与自己的控制台，可以自己写解析记录、做 NS 委托、看到到期时间。

## 平台提供什么

- DNS 解析与基础技术托管，共 12 种记录类型与自定义 TTL
- 独立的域名管理控制台、WHOIS 查询、用户案例展示
- NS 委派与 DNSHE 托管一键写入
- 第三方登录（NodeLoc / GitHub）、邮箱验证码、每日积分

## 平台不提供什么

- 不托管网站内容，也不提供 SLA
- 不是通用顶级域注册商，只分发自己名下的根域名
- 各子域名的内容与运营行为由所有者自行负责，平台不承担用户生成内容引发的法律责任

::: tip 主域名与首推后缀
主域名是 `meoy.top`；`noxc.uk` 是**首推后缀**（后缀列表排第一），不是主域名，Zone 配置不因首推而改变。
:::

## 技术构成

| 层 | 用途 |
|---|---|
| Cloudflare Workers | API、页面直出、静态资源回落 |
| D1 (SQLite) | 用户、域名、记录、积分、举报 |
| KV / R2 | 缓存与用户头像（CI 自动绑定） |
| React + Vite | 控制台与前台页面 |
| VitePress | 你现在看的这份文档 |
