# 用户案例展示

用户可以把自己的域名放到公开案例页，展示站点、图标、标题、介绍与链接。

## 怎么开启

进入「域名管理 → 你的域名 → 用户案例展示」，打开开关。**默认不展示**，只有本人手动开启才会出现。

公开页只列出状态为 `approved`（已开通）的域名。

## 奖励

首次把任意一个已开通域名开启展示，一次性 **+6000 积分**。

- 每账号只发一次：关掉重开、换域名、展示更多域名都不叠加
- 关闭展示不回收
- 管理员与无限积分账号跳过
- 功能上线前就已开启展示的账号，下次进控制台自动补发

奖励金额由后台「站点设置」下发，调成 `0` 即关闭，页面提示会跟着变。

## 入口

首页、控制台侧栏「用户案例」、页脚都可进入 `/showcase`。
