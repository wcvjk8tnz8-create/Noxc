# 快速开始

## 1. 注册账号

在首页填邮箱与密码，按提示完成邮箱验证码。也可以使用 NodeLoc 或 GitHub 登录。

新用户默认获得 **100 积分** 与站点配置的免费域名额度。

## 2. 挑一个后缀

首页「可选后缀」里列出当前开放的根域名，`noxc.uk` 排在首位并标「首推」。每个后缀的积分消耗可能不同，卡片上会直接写明。

::: info 热门标记
首页会把**已开通子域名最多**的那个后缀标成 `HOT`。点「已开通域名」可以展开看每个后缀分别注册了多少。
:::

## 3. 查询并申请

首页搜索框输入前缀，选择后缀后查询。可用时点「立即注册」，按提示完成滑块验证（弹窗只在提交注册时出现），提交后等待审核或即时开通。

管理员手动开通不受滑块验证限制。

## 4. 添加解析

进入「域名管理 → 你的域名」，可以添加 A / AAAA / CNAME / MX / TXT / NS 等记录，也能使用平台验证一键写入。

> NS 记录就是普通 DNS 记录，添加后出现在记录列表里，可编辑、可删除。

## 5. 到期与续期

域名有效期由后台「站点设置 → 域名有效期」决定，默认 365 天。**剩余不足一半即可续期**（365 天对应 182 天窗口），窗口也可手动固定为指定天数。

首页与注册须知的「单次注册 X 天」会跟着后台设置实时变化，不写死。
