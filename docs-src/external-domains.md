# 第三方域名接入（外部域名）

把你**自己拥有的完整域名**接入 Noxc，统一标注 **（外部域名）**。DNS 固定使用 **SEUS DNS**，不提供供应商选择。

> 交互入口：<a href="/external-domains">打开独立的「第三方域名接入」页面 →</a>（可直接打开 / 刷新 / 外链跳入）。控制台「注册域名」卡片下面也保留了同一个入口。

## 准入规则

- 只受理 **gTLD 二级域**，如 `xxx.com` / `xxx.xyz` / `xxx.top`
- **不接受** `xxx.example.com` 这类子域名，也不接受 `example.com` 等文档示例域
- **不接受** `.cn` / `.uk` / `.cc` / `.io` / `.ai` / `.tv` 等 ccTLD 与国家地区后缀
- 本站已生效后缀不能冒充外部域名
- 每账号最多 5 个；不占注册配额、不计入公开统计

白名单在 `GTLD_ALLOWLIST`，要放行新的 gTLD 只需加一项并同步回归。

## 接入流程

1. 在独立页面（或控制台卡片）填写自己的完整域名并提交申请
2. 到**域名注册商**把 NS 改为 `a.ns.fs5.net` / `b.ns.fs5.net`，并先在 s.eus 完成该域名的 DNS 托管（BYOS 需 KYC L2 与人工审核，本站不代做）
3. 点「**用 API 连接**」：站点用「站点设置 → 第三方域名接入」**唯一输入框**里的 `mbt_` MCP Token 调官方 `dns_zones` 找到托管区域与 zone id。该框**保存即生效**，不用配环境变量、不用改 Worker Secret、不用重新部署；Zone 按域名自动查，无需手动填映射
4. **留空也能用**：站点没配令牌时，用户可在连接时临时填自己的 `mbt_` Token，仅本次请求使用、不落库、不回显
5. 等待站长在「站点设置 → 第三方域名接入」审批列表里批准。只有已用 SEUS API 连上 zone 的申请能批准；批准后域名成为根域名，用户可在该后缀下申请子域

批准后 `root_dns_backends` 显式写 `<域名>:seus`，`external_root_lock` 把域名锁死 ——「根域名管理」里那一行的 DNS 下拉禁用并标「SEUS DNS · 第三方接入（固定）」，切换接口也会明确拒绝。`cfCreate / cfUpdate / cfDelete / cfList` 四个入口都分发到站点级 SEUS 后端。

## 权属与边界

不做 TXT 所有权验证 —— 权属链由「SEUS 账号里真实存在托管区域 + 注册商 NS 指向 SEUS + 站长人工批准」三道关构成。

- 令牌只有一个来源（后台 `settings.seus_api_token`），只存服务端；后台 GET 只回掩码，`/api/config` 只有布尔值，脱敏备份会置空
- 记录写进 SEUS 托管区域；**注册商 NS 没改之前，全球 DNS 不会查询这些记录**，写了也不会生效
- 改 NS 前常要先在注册商关掉 DNSSEC，否则切换期间域名可能整体不可达
- 独立表 + 用户索引，不参与公开统计聚合，不会增加 D1 读取量

## 常见问题

| 现象 | 排查 |
|---|---|
| 连上 API、写了记录仍不解析 | `dig NS xxx.com @1.1.1.1` 看权威 NS 是不是 SEUS 两台；申请上点「重新检查 NS」 |
| 提示鉴权失败 | Token 是否 `mbt_` 开头且含 `dns:read` / `dns:write`；别把 AnyNS 的 `nhtdns_` 令牌混进来 |
| 批准后想换 DNS 后端 | 不行，固定 SEUS DNS 是设计口径；下拉禁用且切换接口拒绝 |
| 审批列表里没有申请 | 只有提交过域名、且已用 SEUS API 连上 zone 的申请才排在可批准状态 |

错误与排查顺序统一收在文末附录；站点设置的其它项见 [站点设置](/settings.html)。
