# 已知限制 / FAQ

## 域名

- 不托管网站内容，不提供 SLA，也不是通用顶级域注册商
- 有效期按当前站点设置判定；改设置只影响「何时能续」，不改动已有域名到期时间
- 释放域名不退还「每人注册次数」累计
- 保留前缀（`ai` / `dash` / `nic` 等基线）管理员仍可手动开通

## 邮件

更换邮箱 / 修改密码 / 注册验证码都依赖邮件服务，后台未配置 Resend 或 Brevo 时会明确返回 503，不会假装发送成功。

## 第三方登录

NodeLoc 应用必须勾选 `email` 权限，否则登录会明确报 `email_required`，而不是退回乱码账号。GitHub 的 Star 奖励领取时会实时向 GitHub 复核。

## 存储

KV / R2 由 CI 自动创建并绑定；若 Token 缺权限，绑定会降级但不阻断部署。可在 `/api/config` 查看 `kvBound` / `avatarUpload`。

## 字体

英文使用 Redaction 35（Google Fonts 异步加载），拉不到时回退系统字体，不影响阅读。

## 举报

发现钓鱼、恶意程序、垃圾邮件等违规用途，请到[举报滥用](https://nic.299282.xyz/report)提交。管理员会尽快核查处理。
